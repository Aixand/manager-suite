# Independent Agent Manager integration

Use Agent Manager's [public SDK](python-sdk.md) for native profiles, stable
environment targets, administration, and managed native execution. `Manager`
provides synchronous administration; `Client` execution requires Undercurrent.

Use [Conversation Manager](../../conversation-manager/README.md) for conversation
messaging, streaming, approvals, and retained provider sessions. Applications own
resource composition, workflow routing, and presentation.

The optional [administration MCP interface](profile-management-mcp.md) runs locally.
Applications can build their own proxies using its public tool schemas.

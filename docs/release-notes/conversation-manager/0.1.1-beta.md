# conversation-manager 0.1.1-beta

Add optional shared Codex servers with scoped pooling and independent conversation connections. Separate servers remain the default.

Add rebuildable provider transcripts, live-message reconciliation, and redacted question-answer history. Improve worker startup failures, initialization timeouts, and retained recovery diagnostics.

Include sharing verification and benchmark scripts. Shared mode remains disabled on Windows; macOS has not been benchmarked.

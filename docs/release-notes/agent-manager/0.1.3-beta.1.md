# agent-manager 0.1.3-beta.1

- Expose each provider's existing native home as a built-in `default` profile so users can launch it and discover its sessions without connecting it manually.
- Include the native home in automatic startup selection and use it when a command resolves an omitted profile with no saved preference.
- Keep existing profiles named `default` that point to a different home under an available `default-previous` name, preserving profile identity and session references.
- Limit the interactive Codex continuation list to sessions discovered in the current scan.
